Keyburn — Embedded Messaging test page

This page loads the deployed Embedded Messaging client, not the Agent Builder preview. The enhancedWebChat renderer of the OrderDeliveryMap Custom Lightning Type targets this client, so it is the surface where the map card can actually appear.

  1. Serve this folder over http, not file:// — the client needs a real origin:
    cd web-chat-test; py -3.8 -m http.server 8000, then open http://localhost:8000.
  2. In Setup → CORS, allow http://localhost:8000.
  3. In Setup → Embedded Service Deployments → Agentforce_Service_Agent, make sure the deployment is published and, if the chat refuses to start, that guest access is allowed (the retrieved config has areGuestUsersAllowed=false).
  4. Click the chat button, then ask: "Where is my order 1042? My email is jane.doe@example.com".

If the map card renders here but not in the Builder preview, the preview was simply the wrong surface all along.
